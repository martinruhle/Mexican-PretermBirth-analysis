# `data/example/` — synthetic example dataset

**100% synthetic data. No real patient data of any kind.** These files are
generated by [`scripts/generate_example_data.R`](../../scripts/generate_example_data.R)
with a fixed seed so anyone can run the **full** preterm-birth prediction pipeline
end-to-end without access to the real cohort (which lives outside git, in
`data/raw/`).

They exist so the pipeline is reproducible and reusable: the numbers here are
**not** meaningful and are **not** expected to reproduce the real-cohort results —
different data. The only goal is that the 12 model combinations and every figure
run to completion.

## Files

| File | What it is |
|------|------------|
| `example_genus_rel.csv` | Wide matrix, one row per sample: 70 non-taxa columns (`id`, `index`, `preterm`, `sdg_parto` + clinical) followed by the 97 genus-level taxa as **relative abundances** (each row sums to ~1). |
| `example_genus_abs.csv` | Same columns, but the 97 taxa are integer **read counts** (what ANCOM-BC2 consumes). Read with `read.csv(row.names = "index", check.names = FALSE)`. `rel = counts / rowSums(counts)`, so the two files are consistent. |
| `example_metadata_long.csv` | Longitudinal metadata used by the population/figure chunks: `id`, `index`, `preterm`, `sdg_parto`, `sdg_visita`. Same `index`/`id` as the wide matrix (the data contract requires an exact match). |

The column list (which columns are taxa vs clinical, and the exact taxa names —
including `Escherichia-Shigella`, the `f__/o__/c__/d__` prefixes and the duplicate
`f__Bifidobacteriaceae.1`) is **derived from `config/data_dictionary.csv`**
(`role == "microbiome"`), never hardcoded.

## Cohort design (synthetic)

- 42 subjects, 2–3 longitudinal samples each (~110 samples), ~33% preterm.
- `preterm` (0/1) and `sdg_parto` (weeks at delivery) are **subject-level**
  (constant across a subject's samples); `early_preterm` is 1 when `sdg_parto < 34`.
- `sdg_visita` varies per sample and spans all three trimesters (so the
  trimester figures are populated).
- Vaginal microbiome: *Lactobacillus*-dominated, sparse (~79% zeros), with a
  weak signal injected into *Gardnerella / Prevotella / Sneathia* (dysbiosis is
  more frequent in preterm) and weak clinical associations (age / BMI /
  complications) so the feature-selection approaches are not degenerate.
- Every taxon is present in ≥1 sample (no all-zero column, which would break the
  CLR zero-replacement), and all variables are fully populated.

## How to run the pipeline on this data

```bash
PTB_PROFILE=example Rscript scripts/run_baseline.R
```

`PTB_PROFILE=example` selects the `example:` profile in `config/config.yml`, which
points `matrix_path` / `abs_matrix_path` / `metadata_path` at the three files here
and inherits everything else (columns, approaches, preprocessing, CV, models, …)
from the `default:` profile.

To regenerate the files:

```bash
Rscript scripts/generate_example_data.R
```
